Conversion Algorithm & Rules Specification

Formal steps for converting raw SignFont strings into normalized ASLphabet notation

1 Pre-Fixing & Conversion

  • Handshape Changes: If a secondary handshape or handshape shape change occurs, it converts to wiggle (≈).
  • NULL Discard: Discard all action area marks, expression NMFs, and standalone modifiers mapped to NULL.
  • Doubling: Symbols like ⁼, ᣛ, ᙾ duplicate handshape, location, and movement elements in the sign.

2 Fixing & Normalization

  • Location Reduction: 2 or more LOCs collapse into 1 LOC. The first/salient location is retained.
  • Movement Reduction: 2 or more of the same movement become (mov)И. Max 2 MOV allowed.
  • Neutral Spatial Location: If no explicit location symbol remains, default to neutral spatial area Э.

3 Strict Order Rule: H H L M M

ASLphabet mandates a strict element sequence. Handshapes are swapped from (dominant, non-dominant) to (non-dominant, dominant):

Non-dominant Hand + Dominant Hand + Location (L) + Movements (M M)
